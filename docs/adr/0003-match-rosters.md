# Each match keeps its own roster

A season's teams and players are edited in the console (team editor, roster grid, merges, team-file import), and a player has a stable id and a code unique in the season, written to the `.dvw` player id column, so analysis can follow a player across matches. When a match is created or imported, both rosters are copied into `match_player`, and the match is built and exported from that copy, not from the live team. Editing a team's roster later never rewrites a match already coded, and a late addition or corrected number can be made for one match only; the copy keeps a link to the season player for analysis. We chose this over building every match from the live team tables, which would silently change past exports, and it matches how scouts work in VolleyStation, whose matches have their own player list (docs/research/VOLLEYSTATION.md §10). Matches imported from a file keep the rosters in that file and can't be edited this way yet.
