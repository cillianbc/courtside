# A lineup entered in the console is a StartingSix event

The fold takes a set's starting six from the team sheet's starting zones, which an imported .dvw supplies but a set coded in the console does not. Lineups entered in the console are an event, `Body::StartingSix { team, court }`, kept in the log like any code (undo, corrections and replay work on it) and stored as a `six` event row (season schema version 2; version 1 files are migrated on open). The fold applies it where it stands, replacing that team's six; export writes it as the set's starting zones in `[3PLAYERS]` and writes no `[3SCOUT]` line for it, while the console also writes the `P` and `z` codes marked `>LUp` that DataVolley files carry. We chose this over editing the team sheet (match/player tables) because the PRD makes lineups a fold over the log, and over encoding the six in a `>LUp` code's note, which no other tool would read.
